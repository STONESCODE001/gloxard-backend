Introduction

Welcome to the Gloxad REST API documentation. This API powers secure student and instructor authentication, account onboarding, role authorization, and password recovery workflows.

All requests accept standard JSON payloads with Content-Type: application/json. Every response returns JSON with consistent error envelopes formatted as { "error": "<message>" }.

Base URL & Server

All API requests must be directed to the live Render deployment endpoint below.

Production Base URL (Render)
https://gloxard-backend.onrender.com/api

For local development when running via npm run dev, the API is available at http://localhost:3001/api.

Authentication

Protected endpoints require a signed JSON Web Token (JWT) provided in the HTTP Authorization header using the standard Bearer scheme:

HTTP Header 
Authorization: Bearer <your_jwt_access_token>

Obtain this token by authenticating with your credentials via POST /api/auth/signin. Tokens remain valid for 7 days.

HTTP Status Codes

The Gloxad API returns conventional HTTP response codes to indicate the success or failure of requests. Below is the complete catalog of status codes used across all endpoints:

Status Name Meaning When Returned
200 OK Standard response for successful HTTP requests. Successful login, profile retrieval (/me), OTP pre-check, and password resets.
201 Created Request fulfilled and resulted in a new resource being created. Successful user registration (POST /api/auth/signup).
400 Bad Request Server cannot process request due to client error or missing required fields. Missing email/password, malformed input, invalid OTP, or expired OTP.
401 Unauthorized Request lacks valid authentication credentials. Missing, expired, or malformed Bearer token on protected endpoints, or invalid login credentials.
403 Forbidden Server understands request but refuses to authorize access. Attempting access without verified role or with pending instructor approval.
404 Not Found The requested endpoint or resource does not exist. User account not found, or invalid URL path.
409 Conflict Request cannot be completed due to a conflict with existing state. Attempting to register with an email that is already in use.
422 Unprocessable Entity Request body is syntactically correct but semantically invalid. Weak password that fails validation criteria, or invalid email format.
429 Too Many Requests Client has sent too many requests in a given amount of time (rate limit). Exceeding rate limit windows on authentication attempts or OTP verification dispatches.
500 Internal Server Error Server encountered an unexpected condition that prevented request fulfillment. Unexpected database errors, SMTP dispatch failures, or unhandled server exceptions.

Standard Error Response Format

All 4xx and 5xx responses strictly adhere to the unified error envelope structure:

JSON Error Envelope 
{
  "error": "Detailed explanation of the error condition"
}

Endpoints Reference

Complete reference of available REST endpoints, required parameters, and response structures.

GET /api/health Public
Returns system operational status and process uptime. Used by Render health monitors and uptime checkers.
Request 
curl -X GET https://gloxard-backend.onrender.com/api/health
Response 200 OK 
{
  "status": "ok",
  "uptime": 14285.34
}
POST /api/auth/signup Public
Registers a new user account. Students are automatically approved. Instructors are registered with approvalStatus: "pending" and sent a 4-digit verification OTP via email.
Field Type Status Description
firstName string Required User's first name
lastName string Optional User's last name (defaults to empty string)
email string Required Valid email address (must be unique)
password string Required Account password (salted & hashed via bcrypt)
role string Optional student (default) or instructor
Request Payload (JSON) 
{
  "firstName": "Alex",
  "lastName": "Johnson",
  "email": "student@gloxad.com",
  "password": "Password123!",
  "role": "student"
}
Response 201 Created 
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "_id": "673f8a92b234fa001234abcd",
    "email": "student@gloxad.com",
    "firstName": "Alex",
    "lastName": "Johnson",
    "username": "alexj",
    "role": "student",
    "isEmailVerified": false,
    "approvalStatus": "approved",
    "certifications": [],
    "avatarUrl": "",
    "biography": "",
    "title": "",
    "phoneNumber": "",
    "socialLinks": {},
    "notificationPreferences": {}
  }
}

Authenticates credentials (email and password) and issues a signed stateless JWT token valid for 7 days.
Field Type Status Description
email string Required Registered account email
password string Required Account password

  "password": "Password123!"

    "email": "student@gloxad.com",
    "firstName": "Alex",
    "lastName": "Johnson",
    "role": "student",
    "approvalStatus": "approved",
    "isVerified": false,
    "avatarUrl": ""
  }
}

POST /api/auth/signout Public
Acknowledges client session termination. The client application should discard the stored JWT token.
Response 200 OK 
{
  "message": "Successfully signed out"
}
POST /api/auth/verify-email Public
Validates a 4-digit numeric OTP sent via email. Sets isVerified: true and consumes the verification record.

    "certifications": [],

    "biography": "",

POST /api/auth/resend-verification Public
Issues a fresh 4-digit verification OTP and emails it. Returns a generic 200 message regardless of whether the account exists or is already verified.
Request Payload 
{
  "email": "student@gloxad.com"
}
Response 200 OK 
{
  "message": "If this account needs verification, a new code has been sent."
}
POST /api/auth/forget-passwd Public
Initiates password recovery by dispatching a 5-digit numeric OTP with a 15-minute expiration to the user's email. Features anti-enumeration security.
Request Payload 
{
  "email": "student@gloxad.com"
}
Response 200 OK 
{
  "message": "Password reset OTP dispatched to email"
}
POST /api/auth/verify-otp Public
Pre-validates that a 5-digit recovery OTP is active and correct without consuming it. Allows UI multi-step wizards to proceed to the new password step safely.
Request Payload 
{
  "email": "student@gloxad.com",
  "otp": "72941"
}
Response 200 OK 
{
  "valid": true,
  "message": "OTP is valid"
}
POST /api/auth/reset-passwd Public
Consumes the 5-digit recovery OTP and updates the account password with a new salted hash.
Request Payload 
{
  "email": "student@gloxad.com",
  "otp": "72941",
  "newPassword": "NewSecurePassword123!"
}
Response 200 OK 
{
  "message": "Password reset successfully. You can now sign in with your new password."
}
POST /api/auth/update-password Bearer Token
Allows an authenticated user to change their password by validating their current password against the stored bcrypt hash.
Request Payload 
{
  "currentPassword": "OldPassword123!",
  "newPassword": "NewSecurePassword456!"
}
Response 200 OK 
{
  "message": "Password updated successfully"
}

Response 200 OK

POST /api/upload/presigned-url Bearer Token
Generates a short-lived (15-minute) AWS S3 PUT presigned URL for direct client-side media offloading. Guarantees zero raw file byte streaming on the API server.
Field Type Status Description
filename string Required Original filename of the target asset (e.g. profile_avatar.png)
fileType string Required MIME type of the upload (e.g. image/png, video/mp4, application/pdf)
folder string Optional Target S3 folder prefix: avatars, courses, certifications, resources (defaults to resources)
Request Payload (JSON) 
{
  "filename": "lecture1_intro.mp4",
  "fileType": "video/mp4",
  "folder": "courses"
}
Response 200 OK 
{
  "uploadUrl": "https://gloxad-media-bucket.s3.us-east-1.amazonaws.com/courses/1727520000000-abc123_lecture1_intro.mp4?X-Amz-Algorithm=...",
  "fileUrl": "https://gloxad-media-bucket.s3.us-east-1.amazonaws.com/courses/1727520000000-abc123_lecture1_intro.mp4",
  "key": "courses/1727520000000-abc123_lecture1_intro.mp4",
  "expiresIn": 900
}
