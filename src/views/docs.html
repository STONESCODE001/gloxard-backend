Developer API Reference & Documentation

Clean, technical REST API specification and interactive endpoint reference for Gloxad Academy. All client errors strictly observe the { "error": "<message>" } standard and retain _id identifiers.

🔒 Authentication & Account Recovery (/api/auth) 9 Endpoints
POST /api/auth/signup — User Registration (Student or Instructor) Public ▶
Registers a new user account. Students are automatically approved. Instructors are registered with approvalStatus: "pending" and trigger a 4-digit OTP email verification dispatch.
Field Type Required Description
firstName string Required User's first name
lastName string Optional User's last name (defaults to empty string)
email string Required Unique user email address
password string Required Account password (salted & hashed via bcrypt)
role string Optional Either student (default) or instructor
📋 Request Payload (JSON) 
{
  "email": "student@gloxad.com",
  "password": "Password123!",
  "firstName": "Alex",
  "lastName": "Johnson",
  "role": "student"
}
📤 Success Response 201 Created 
{
  "message": "User registered successfully",
  "user": {
    "_id": "673f8a92b234fa001234abcd",
    "email": "student@gloxad.com",
    "firstName": "Alex",
    "lastName": "Johnson",
    "role": "student",
    "isVerified": false
  }
}
POST /api/auth/signin — User Authentication & JWT Issuance Public ▶
Authenticates user credentials (email or username with password) and returns a stateless signed JWT token valid for 7 days.

{
  "email": "student@gloxad.com",
  "password": "Password123!"

    "firstName": "Alex",
    "lastName": "Johnson",
    "role": "student",
    "approvalStatus": "approved",
    "isVerified": false,

  }
}
GET /api/auth/me — Get Current User Context Bearer Token ▶
Returns the fully-hydrated user profile for the caller associated with the validated Bearer token. Strips sensitive fields like password and internal __v.
📋 Headers 
Authorization: Bearer <JWT_TOKEN>
📤 Success Response 200 OK

POST /api/auth/signout — Sign Out & Invalidate Client Session Public ▶
Acknowledges client-side token discard and session termination.
📤 Success Response 200 OK 
{
  "message": "Successfully signed out"
}
POST /api/auth/verify-email — Verify Email with 4-Digit OTP Public ▶
Validates a 4-digit numeric OTP sent upon instructor registration or email verification request. Marks isVerified: true and consumes the OTP record.
📋 Request Payload (JSON) 
{
  "email": "instructor@gloxad.com",
  "otp": "4821"
}
📤 Success Response 200 OK 
{
  "message": "Email verified successfully"
}
POST /api/auth/forget-passwd — Request 5-Digit Password Recovery OTP Public ▶
Initiates the password recovery flow by generating a 5-digit numeric OTP with a 15-minute TTL index and dispatching it to the user's email. Includes anti-enumeration protection.
📋 Request Payload (JSON) 
{
  "email": "student@gloxad.com"
}
📤 Success Response 200 OK 
{
  "message": "Password reset OTP dispatched to email"
}
POST /api/auth/verify-otp — Validate Password Reset OTP (Pre-Check) Public ▶
Validates that the 5-digit recovery OTP is active and correct without consuming it, allowing frontend UI wizards to advance to the new password entry step.
📋 Request Payload (JSON) 
{
  "email": "student@gloxad.com",
  "otp": "72941"
}
📤 Success Response 200 OK 
{
  "valid": true,
  "message": "OTP is valid"
}
POST /api/auth/reset-passwd — Reset Password with Validated OTP Public ▶
Consumes the 5-digit OTP record, updates the user's account password with a new bcrypt hash, and enables immediate sign-in with the new credentials.
📋 Request Payload (JSON) 
{
  "email": "student@gloxad.com",
  "otp": "72941",
  "newPassword": "NewSecurePassword123!"
}
📤 Success Response 200 OK 
{
  "message": "Password reset successfully. You can now sign in with your new password."
}
POST /api/auth/update-password — Authenticated Password Update Bearer Token ▶
Allows an authenticated user to update their account password by verifying their existing password and hashing the new password.
📋 Request Payload (JSON) 
{
  "currentPassword": "OldPassword123!",
  "newPassword": "NewSecurePassword456!"
}
📤 Success Response 200 OK 
{
  "message": "Password updated successfully"
}
